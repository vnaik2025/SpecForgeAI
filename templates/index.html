              AI
            

            

              
What is SpecForge AI?

              

                SpecForge AI is an autonomous technical architecture engine. It takes raw project requirements (PRDs, Word documents, PDFs, or user stories) and synthesizes production-ready developer specifications (AGENT.md, ARCHITECTURE.md, SETUP.md, SKILLS.md, API_SETUP.md), ready-to-run folder structures, and interactive UI prototypes in seconds.
              

            

          


          

            

              

                1
                Ingest Document or Raw Scope
              

              

                Upload a Word document (.docx), .pdf, or paste your requirements directly. SpecForge handles client-side and server-side text extraction automatically.
              

            


            

              

                2
                Automatic Stack & Module Ideation
              

              

                Click Analyze Scope. The AI classifies Frontend, Backend, Database, and external services, recommends an architectural blueprint, and ideates 4–8 functional modules.
              

            


            

              

                3
                Refine Stack & Directives
              

              

                Add custom technology chips (e.g. Tailwind, PostgreSQL, Redis) or supply strict constraints in the VIP Directives box (e.g. "Use DRF SimpleJWT", "Implement Stripe Webhooks").
              

            


            

              

                4
                Generate Scaffold & Prototype
              

              

                Click Generate Specifications. The engine outputs 6 detailed specification files, compiles a live single-file HTML UI prototype, and packages a downloadable ZIP.
              

            

          

        


        
        

          

            SpecForge AI structures its generated blueprints into cleanly separated frontend/ and backend/ specifications designed for coding agents (Cursor, Claude Code, GitHub Copilot, Antigravity) and human engineers:
          


          

            

              

                
                  AGENT.md
                  Autonomous Coding Agent Context
                
                Cursor / Claude / Copilot
              

              

                The primary brain for AI pair programmers. Defines system role, tone, mandatory code standards, file conventions, prohibited libraries, and error-handling protocols.
              

            


            

              

                
                  ARCHITECTURE.md
                  System Architecture & Schemas
                
                System Design
              

              

                High-level architecture documentation covering module boundaries, database schemas, primary/foreign keys, state machines, and data flow pipelines.
              

            


            

              

                
                  SETUP.md
                  Deterministic Setup Commands
                
                DevOps & Local Setup
              

              

                Deterministic, copy-paste terminal commands to initialize the virtual environment, install exact package dependencies, run database migrations, and populate `.env` files.
              

            


            

              

                
                  SKILLS.md
                  Specialized Workflows & Tooling
                
                Agent Workflows
              

              

                Actionable step-by-step verification routines, unit test execution recipes, linting tasks, and specialized domain workflows for autonomous execution.
              

            


            

              

                
                  API_SETUP.md
                  REST API Contracts & Headers
                
                API Specs
              

              

                Endpoint contracts, HTTP methods, authentication tokens, payload schemas, query parameters, and expected HTTP status codes.
              

            


            

              

                
                  UI_PROTOTYPE.html
                  Interactive HTML/Tailwind Prototype
                
                Frontend Canvas
              

              

                Standalone single-file prototype containing responsive views, live mock records, a Kanban board, search filtering, and interactive dummy authentication.
              

            

          

        


        
        

          

            
Specification Studio Features

            

              The Specification Studio is your centralized development console for reviewing and exporting blueprints:
            

          


          

            

              File Tree Navigation
              

                Quickly toggle between frontend/ and backend/ files in the left sidebar. Badges show completion status.
              

            


            

              Preview vs Raw Source
              

                Switch between rendered GitHub-style Markdown and syntax-highlighted raw markdown with a 1-click clipboard copy button.
              

            


            

              Big Window UI Canvas
              

                Click Open Big Window to preview the interactive HTML prototype in Desktop (1440px), Laptop (1024px), Tablet (768px), or Mobile (375px) viewports.
              

            


            

              Simulated Dummy Auth
              

                Prototypes support interactive dummy login and logout. Enter demo credentials, test protected views, and verify responsive navigation with 0 page reloads.
              

            

          


          

            Exporting to Your IDE
            

              Click Download Complete Scaffold (.ZIP) in the top studio toolbar. Unpack the zip file into your local project root or open it directly in VS Code, Cursor, or WebStorm.
            

          

        


        
        

          

            
Writing High-Performance Scope Documents

            
    
              
  • List Core Entities: Explicitly mention entities like Orders, Inventory, Customers, Dispatch for accurate database models.
    • 
              
  • Specify User Roles: Mention access levels (e.g., Admin, Store Manager, Customer) so the API and UI prototypes generate authentic role-based interfaces.
    • 
              
  • Use Technical Keywords: If you need specific libraries (e.g. Celery, Redis, Stripe, Tailwind), include them in the document or the custom tech stack tags.
    • 
            

          


          

            
Cryptographic Token Caching (0 Tokens on Repeats)

            

              SpecForge AI computes a SHA-256 fingerprint hash of your scope text. If you re-analyze a project, reload the page, or test sample prompts, responses return in ~10 milliseconds consuming 0 LLM tokens.

              AI
            

            

              
Keyless Multi-Model Frontier AI with Puter.js

              

                Puter.js allows SpecForge AI to directly query frontier AI models (Gemini 2.5 Flash, DeepSeek V3, GPT-4o Mini, Llama 3.3 70B, Mistral Small 24B, Claude 3.5 Haiku) from your browser without developer API keys or server configuration.
              

            

          


          

            

              Resilient Auto-Model Failover
              

                If any provider returns a rate limit (HTTP 429), quota exhaustion, or network timeout, the engine automatically catches the exception, updates the terminal log, and retries the phase with the next model in the fallback chain (Gemini -> DeepSeek -> GPT-4o Mini -> Llama 3.3 -> Mistral).
              

            


            

              Review-Driven Development Workflow
              

                SpecForge AI does not stop at raw code generation. An Architect Agent first ideates entities and bounded contexts, followed by a Reviewer Quality Gate that audits API contracts and security rules before synthesizing dual-tier packages and UI prototypes.
              

            

          


          

            Dual-Engine Flexibility
            

              Toggle anytime between the Server Engine (Gemini API with Redis/LocMem caching) and the Puter.js Multi-Model Client Engine. Generated specifications synchronize seamlessly with your account and remain 100% exportable as standard zip files.
